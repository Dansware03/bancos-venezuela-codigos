Campos del JSON

Esquema simple y directo para cualquier integración.

nombre string Nombre oficial del banco
rif string RIF del banco
filename string Nombre del archivo de logo en images/

Uso rápido

Copia y pega en tu proyecto.

JavaScript 
import bancos from './bancos.json';

// Buscar por código
const banco = bancos.find(b => b.codigo === '0102');

// Ruta del logo
const logo = `./images/${banco.filename}`;
Python 
import json

with open('bancos.json') as f:
    bancos = json.load(f)

banco = next(b for b in bancos if b['codigo'] == '0102')
logo = f"images/{banco['filename']}"

¿Colaboras?

Proyecto de apoyo abierto a mejoras. Los logos actuales son un punto de partida — cualquier aporte que mejore la calidad o consistencia ayuda a quienes lo usan.

  • ✦ Iconos de mejor calidad — más nítidos o con fondo transparente
  • ✦ Formato 512×512 px — tamaño uniforme para apps y web
  • ✦ Versiones vectorizadas — SVG para escalado sin pérdida
  • ✦ Ideas y sugerencias — alias, nuevos campos, normalización
